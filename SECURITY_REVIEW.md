# Security Review Notes

This submission copy was prepared for manual review with publish-risk files
excluded.

Excluded from the review repository:

- Git metadata and other hidden dotfiles
- Flutter and Dart generated tool caches
- Generated build cache directories except the visible `public` review build
- Android `local.properties`
- Machine-specific editor settings
- Packet captures, keys, certificates, databases, and env files if present

Secret scan terms checked included API keys, tokens, passwords, bearer headers,
private keys, database URLs, and common AI provider key names. No hard-coded
credentials were found in the submission copy.
